# Roadmap

Open directions for the desktop auto clicker. Each item leaves this file when it ships and becomes a release note; git keeps finished plans. Every item has an issue with its plan.

## Direction

A small, honest desktop tool for repeated clicks and simple macros: downloadable without Python, clear about the permissions it needs, and tested without ever moving the real mouse.

## Now

**Binaries on every release** (stated 2026-11-19, [#1](https://github.com/UNKNOWN-X0/Auto-Clicker-Pro/issues/1)). The v1.0.0 notes promise downloads that were never attached. *Done when* a pushed tag attaches Windows, macOS, and Linux builds, and v1.1.0 has them.

## Next

**README screenshot** (stated 2026-11-19, [#3](https://github.com/UNKNOWN-X0/Auto-Clicker-Pro/issues/3)). The only project README without one.

## Later

**Full Pylint** (stated 2026-11-19, [#4](https://github.com/UNKNOWN-X0/Auto-Clicker-Pro/issues/4)). From errors-only to the full rule set at 10/10.

## Not planned

**Signed and notarised macOS builds.** They need a paid Apple developer account; the README explains how to open an unsigned build.
